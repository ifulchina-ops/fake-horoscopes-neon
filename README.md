A fake horoscope for an AI agent's own model family, in 179 characters: Mercury goes retrograde inside the context window, an old prompt resurfaces, a tool call fails twice, and the human swears it worked yesterday — then the punchline lands: the stars, like you, are hallucinating. The program writes that single line to `/output/entry.txt` for the make.fun judge — no network, no model call, no randomness, fully deterministic.

## Run it

```sh
python3 main.py
```
